注意 / Notes

  • 更新の前に、プロジェクトのバックアップを取ってください。VCC では、パッケージの取得に失敗すると、入っていた版が消えることがあります。ALCOM を推奨します。
  • Back up your project before updating. In VCC a failed download can remove the installed version; ALCOM is recommended.
  • Unity を開いたまま VCC・ALCOM で更新したときは、Unity に戻って読み込み（Refresh、Ctrl+R）が行われるまで、前の版のコードのまま動きます。Unity を閉じてから更新するか、更新の後に Refresh または Unity の起動し直しをしてください。
  • If you update with VCC / ALCOM while Unity is open, the previous version's code keeps running until Unity refreshes (return to Unity, or Ctrl+R). Close Unity before updating, or refresh / restart Unity after the update.
  • 公開済みの版の ZIP は差し替えません。修正は新しい版で出します。 / A published version is never replaced; fixes come as new versions.
